# n8n community nodes for Trailgauge

This directory is a complete n8n community node package. It is generated by PipeTrails from your product profile.

## Install in n8n

In n8n, open Settings, then Community Nodes, then Install. Enter `n8n-nodes-trailgauge`.

## Publish

From this directory run:

    npm login
    npm publish --access public

n8n requires packages named `n8n-nodes-*` with the keyword `n8n-community-node-package`.
